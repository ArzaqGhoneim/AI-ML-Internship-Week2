# AI & Machine Learning Internship – Week 2

## Deep Learning with PyTorch

This repository contains my Week 2 tasks for the **AI & Machine Learning Internship at Skill Set Go EduTech**.

The focus of this week was building and evaluating Deep Learning models using **PyTorch**.

## Tasks

### Task 2.1 – Neural Network in PyTorch

* Built a Feed-Forward Neural Network (MLP) using PyTorch.
* Worked with Tensors, Datasets, and DataLoaders.
* Implemented a loss function and optimizer.
* Trained and evaluated the model on the Fashion-MNIST dataset.
* Achieved approximately **88% test accuracy**.

### Task 2.2 – CNN Image Classifier

* Built a Convolutional Neural Network (CNN) using PyTorch.
* Applied convolution, ReLU activation, pooling, and fully connected layers.
* Trained the model on Fashion-MNIST.
* Evaluated the model using classification accuracy.

### Task 2.3 – Hyperparameter Experimentation

Conducted controlled experiments by changing:

* Optimizer
* Learning Rate
* Batch Size
* Number of Epochs

The experiments were documented and compared to analyze their effect on model performance.

### Task 2.4 – Deep Learning Technical Report

A technical report summarizing:

* Model architectures
* Experimental setup
* Performance results
* Hyperparameter comparisons
* Key observations and conclusions
